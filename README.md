# GramaYatri 🛖🚜

**GramaYatri** (Village Traveler) is an Android application designed to bridge the gap between urban explorers and the rich cultural heritage of rural India. It provides a platform to discover hidden gems, experience authentic village life, and support local rural economies.

## 🌟 Features

*   **Discover Villages:** Explore a curated list of villages with unique cultural, historical, or natural significance.
*   **Authentic Experiences:** Find local stays, traditional crafts, and farm-to-table culinary experiences.
*   **Navigation:** Get detailed routes and travel tips for reaching remote locations.
*   **Local Guides:** Connect with local experts who can provide an insider's view of their village.
*   **Sustainable Tourism:** Promoting eco-friendly travel and supporting local artisans.

## 🛠️ Tech Stack

*   **Language:** [Kotlin](https://kotlinlang.org/)
*   **UI Framework:** [Jetpack Compose](https://developer.android.com/jetpack/compose)
*   **Architecture:** MVVM (Model-View-ViewModel)
*   **Networking:** Retrofit / Ktor
*   **Dependency Injection:** Hilt / Koin
*   **Database:** Room (for offline access)

## 🚀 Getting Started

### Prerequisites
*   Android Studio Ladybug (or later)
*   JDK 17 or higher
*   Android SDK Level 24+

### Installation
1.  **Clone the repository:**
    ```bash
    git clone https://github.com/SHAMANTH-J/GramaYatri.git
    ```
2.  **Open in Android Studio:**
    *   File -> Open -> Select the `GramaYatri` folder.
3.  **Build the project:**
    *   Let Gradle sync and build the project.
4.  **Run the app:**
    *   Connect an emulator or a physical device and click the 'Run' icon.
